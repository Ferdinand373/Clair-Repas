# Vignettes Automne gourmand

Aucune photo définitive incluse. Ajouter uniquement des fichiers WebP autorisés, 160 × 160 px (80 px affichés), cible ≤ 20 Ko chacun ; maximum dix images. Attribuer à la recette existante un champ thumbnail : assets/recipes/automne/identifiant.webp. Le chemin est validé et les images sont chargées paresseusement, sans téléchargement de remplacement. Une image absente ou cassée laisse une carte complète sans emplacement vide.

Lors de l'ajout, déclarer les chemins dans AUTUMN_THUMBNAILS du service worker : ils sont conservés à la première consultation et disponibles hors ligne ensuite. Aucun préchargement des images du catalogue.
